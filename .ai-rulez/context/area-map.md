## Area Map

R-universe registry for xberg-io; the GitHub repository must stay named `xberg-io.r-universe.dev`.

- `packages.json` — each R package's source `url`, `branch` and `subdir`; r-universe builds from it
- `.github/` — issue and PR templates and their validation workflows
